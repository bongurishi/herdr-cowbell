# Support

Need help with herdr-cowbell? Use the right channel so your request reaches the right people.

## Questions and Usage Help

For general questions, configuration help, or usage discussions, start a conversation in **GitHub Discussions**.

## Bug Reports

If something is broken or not working as expected, [open a bug report](https://github.com/dvoraj75/herdr-cowbell/issues/new?template=bug_report.yml).

Please include:
- herdr version
- herdr-cowbell version
- Operating system and terminal
- Relevant configuration
- Output from `herdr plugin list` or `ctl.js` status
- Relevant plugin logs

## Feature Requests

Have an idea for improving herdr-cowbell? Submit a feature request through the repository's issue templates.

## Security Issues

For security vulnerabilities, follow the private reporting instructions in [SECURITY.md](SECURITY.md). Do not report security issues publicly.
