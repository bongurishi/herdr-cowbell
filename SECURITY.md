# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of herdr-cowbell.

| Version | Supported |
|---|---|
| Latest release | Yes |
| Older releases | No |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately.

**Do not open a public GitHub issue for security vulnerabilities.**

Use GitHub's private vulnerability reporting feature:

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Provide a clear description of the issue and steps to reproduce it.

Please include:
- A description of the vulnerability.
- The affected version.
- Steps to reproduce the issue.
- Any potential impact.

The maintainers will review the report and respond as soon as reasonably possible.

Please allow maintainers time to investigate and fix the issue before publicly disclosing it.
